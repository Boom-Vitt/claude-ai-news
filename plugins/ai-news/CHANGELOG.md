# Changelog

All notable changes to the **AI News** plugin are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-06-11

### Added
- Initial release.
- Commands: `/ai-news:daily`, `/ai-news:trending`, `/ai-news:summarize`, `/ai-news:write`.
- Agents: `news-researcher` (multi-source gathering + verification), `news-editor` (fact-check + copy edit).
- Skill: `newsroom-style` — sourcing standards and anti-fabrication guardrails applied across all commands.
